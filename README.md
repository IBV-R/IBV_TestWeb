# IndusBridge Ventures — Website Redesign (Next.js + Tailwind)

Revamp of **Indusbridgeventures.com** to match the visual and content sophistication of tier‑1 VC firms, with an institutional deep‑tech / defence aesthetic.

## Stack

- Next.js (App Router)
- React
- Tailwind CSS v4 (CSS-first configuration)
- TypeScript

## Project goals

- Clear positioning: **India‑focused defence, dual‑use, and deep tech investor**
- Strong information hierarchy and scannable sections
- Professional tone and tier‑1 VC design patterns
- Responsive + accessible across devices

## Documentation

- Phase 1: Competitive analysis — [`docs/competitive-analysis.md`](./docs/competitive-analysis.md)
- Phase 2: Design pointers — [`docs/design-pointers.md`](./docs/design-pointers.md)

```bash
npm install
npm run dev
```

Then open http://localhost:3000
